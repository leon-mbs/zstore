Опис JS
Скрипт, що виконує запит до вибраного SMS сервісу, має реалізувати тіло вбудованої функції яка буде викликатись системою з двома строковими параметрами: phone i sms. Третій параметр - функція callback що приймає строковий параметр. В callback можна передати строку помилки, якщо така виникне. Якщо помилок нема callback викликається з порожньою строкою.
PHP
Для PHP скрипту на вході автоматично створяться змінні $phone i $sms з даними. Скрипт має повернути пусту строку або текст помилки, якщо така виникла

Технічно під виглядом SMS відправки може бути реалізований будь який сервіс повідомлень що має відповідний API
