Встановлення та налаштування

Оскільки ПЗ вільнорозповсюджуване оплата не потрібна але можна задонатити на розвиток проекту.

Вимоги до ПЗ:
PHP8.1+
Apache (необхідна підтримка .htaccess)
Mysql 8.0+ (MariaDB)
Програма спроектована на максимальну простоту і дешевизну розробки, а не на максимальне навантаження. Якщо передбачається активна торгівля з великим обсягом товарів, по мiрi накопичення даних будуть потрібні значні обчислювальні ресурси.
Для PHP рекомендується не менше 512MB пам'яті та не менше 300 секунд timeout. Також рекомендується збільшити пам'ять для сервера БД.

Установка програми може бути виконана як на хостингу, так і на локальному сервері, або персональному комп'ютері. Може бути використаний самий недорогий, не потребуючий спеціального адміністрування, віртуальний хостинг

Рекомендований хостинг ukraine.com.ua

Процесс налаштування залежить від рівня користувача.

Для IT спеціалістів:
1. Отримати дистрибутив з GitHub репозиторію (Не забуваємо ставити зiрочку :) ) .
2. Скопiювати вмiст www в корiнь сайту. Надати право запису в папки logs та upload (для Лiнукса)
3. Виконати загрузку бібліотек за допомогою Composer.
4. Створити БД (кодування utfmb4_general_ci) та виконати SQL скрипт /db/db.sql . (Файли update*.sql виконувати не треба).
В PhpMyAdmin скрипти виконувати через iмпорт
5. Прописати конект до БД в config/config.php.
6. Увійти дефолтним користувачем admin admin (дефолтний пароль слід змінити на сторінці профілю).
7. Задати необхідні налаштування - склад за замовчуванням, назву фірми, оперативне меню у вигляді кнопок, типи цін та ін.

Користувачі, що не є IT спеціалістами
можуть встановити зібрану, готову до роботи програму на локальному комп'ютері.

Для цього завантажити збiрку (для Windows), на основі проекту XAMPP, розпакувати архів в корінь диску c:. Файл для запуску c:/xampp/xampp-control.exe.


Якщо Apache і Mysql стартували після натискання відповідних кнопок, сайт повинен відкритися в браузерi за адресою http://localhost/. Далі панель можна згорнути.
Папка з сайтом (на випадок ручних оновлень) - htdocs.
Сторінка управління БД (для ручних оновлень) за адресою http://localhost/phpmyadmin (якщо запитає акаунт- root root)
Після закінчення роботи або перед вимкненням комп'ютера слід зупинити XAMPP. В першу чергу потрібно зупинити MySQL, щоб уникнути втрати даних.

Для Mac OS i Linux можна завантажити збiрку XAMPP.
Далi завантажити дистрибутив в зборі з усіма бібліотеками (папка vendor) та пропустити пункти 1 i 3 вище.

В обох збiрках пiсля закiнчення роботи слід зупинити програму кнопками Stop apache i Stop mysql щоб не пошкодити данi при виключеннi ПК

На випадок проблем з XAMPP можна завантажити альтернативну збiр , розпакувати архів (в папку без пробiлiв в шляху), запустити UniController.exe, натиснути Start Apache, Start Mysql. Далі натиснути View www (або відкрити вручну сайт в браузері за адресою http://localhost/ )
Папка з сайтом (на випадок ручних оновлень) - www.
